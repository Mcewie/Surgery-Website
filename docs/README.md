# Documents

Downloadable buyer documents go in this folder and are linked from the
**Documents** table in `index.html`.

Use descriptive filenames that include a date, for example:

- `riverbank-westcott-title-register-and-plan-2026-10.pdf`
- `riverbank-westcott-legal-pack-v1-2026-10.pdf`
- `riverbank-westcott-special-conditions-and-addenda-2026-10.pdf`
- `riverbank-westcott-occupation-summary-solicitor-2026-10.pdf`
- `riverbank-westcott-measured-survey-and-floor-plans.pdf`
- `riverbank-westcott-epc.pdf`
- `riverbank-westcott-planning-appraisal-2026-10.pdf`
- `riverbank-westcott-planning-status-and-history-2026-10.pdf`
- `dorking-medical-practice-hearing-statement-2026-09-18.pdf`

**Only upload documents that the selling solicitor has approved for the
buyer pack.** Don't upload the family's evidence archive, the working
evidence bundle or any privileged legal advice. Everything in this folder
is publicly downloadable once the site goes live.
